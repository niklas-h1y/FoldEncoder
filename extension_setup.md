# Extension Setup: Page Fold Translator 🥠

Want to turn any webpage on the internet into your encrypted Unicode Fold language? This guide shows you how to install the custom browser extension version of the tool.

The extension uses browser scripting privileges to safely step through a webpage's DOM tree, translating plain text blocks into your compressed Unicode symbols while ignoring structural HTML tags, code elements, and styling sheets.

---

## 💻 Desktop Installation (Chrome, Brave, Edge, Opera)

1. **Prepare the Files:** Create a folder on your computer named `Fold_Translator`. Save the three extension files (`manifest.json`, `popup.html`, and `popup.js`) inside it.
2. **Open Extensions Portal:** Navigate to `chrome://extensions/` in your browser URL bar.
3. **Turn on Developer Mode:** Toggle the **Developer mode** switch in the top-right corner to **ON**.
4. **Deploy the Directory:** Click the **Load unpacked** button in the top-left corner.
5. **Select Folder:** Choose your `Fold_Translator` folder. 

🚀 *The extension icon will pop up in your browser menu. Open any site (like Wikipedia) and tap the button to encrypt the text!*

---

## 📱 Mobile Installation (Android / Tablet)

Standard mobile browsers do not allow custom unpack installations, but you can run this scrambler on mobile devices using an extension-supported client:

1. **Get your Environment:** Download **Lemur Browser** or **Mises Browser** directly from the official Google Play Store.
2. **Download your Files:** Download the source repository as a ZIP archive onto your mobile device storage downloads history.
3. **Open Extensions Manager:** In Lemur Browser, tap the **Shield/Extensions** icon at the top right next to the menu dots.
4. **Enable Developer Settings:** Switch the **Entwicklermodus (Developer Mode)** toggle button to **ON**.
5. **Import ZIP:** Click the **"+ (from zip)"** or **"Local"** upload button and select your downloaded repository ZIP file.

🚀 *The tool will load instantly. Open any project page, click your top bar extension icon, select **Unicode Fold Translator**, and hit "Fold This Page"!*
